# Deep Dives

My personal study notes on real-world software architecture — written by actually reading company engineering blogs closely enough to explain the mechanics back to myself, not a curated reference for other people.

Each page picks one system at one company and works through: the actual problem it solves, how it works mechanically, the trade-offs the team made explicitly, where it still breaks, and what I still don't understand about it.
